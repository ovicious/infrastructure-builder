# Roadmap

- [x] Milestone 0: Python package skeleton, CLI entry point, documentation,
  and smoke tests.
- [x] Milestone 1: Typed configuration, YAML I/O, local wizard, and validation.
- [ ] Milestone 2: Deterministic planning and safe file generation.
- [ ] Milestone 3: Approval-gated local execution and managed state.
- [ ] Milestone 4: Optional Ollama configuration assistant.
- [ ] Milestone 5: A narrowly scoped Terraform provisioning adapter.
- [ ] Milestone 6: Kubernetes and additional platform features.

Milestones 2–6 are planned work, not functionality provided by the current
release.
